# 异界三国

手机与桌面浏览器可玩的静态网页三国游戏。主菜单、人物创建和战斗由Canvas绘制；姓名输入使用原生输入框支持中文输入法。序章已接入：古道迷雾后的村道冲突、手动雷系教学战、三兄弟对五队官兵，以及黄巾营地对话。

主菜单提供新游戏、载入游戏、设置、关于。创建人物分两步：第一步选择难度、重掷潜力和被动，五项1级属性固定为10，使用五行属性表和三张纵向被动卡片展示，隐藏武器熟练度；第二步输入姓名、选择全身造型。返回上一步保留已有结果。默认初出茅庐及第二个形象；进入即重掷潜力，空名用无名氏，自定义最多四字。只选难度，自由搭配任何武器。地狱潜力全1、被动全白；主角剧本五项潜力全100、所有武器熟练度固定0、被动仅金红。所有难度的开局武器熟练度均固定0，重掷只影响潜力和被动技能。重掷无闪屏，空格仍可操作但不展示说明。

五档难度、62种开局被动、29种可扩充的武器熟练度及存档兼容见[新游戏与被动设定.md](./新游戏与被动设定.md)。全部武器定位与地下城堡2参考分支见[游戏设定.md](./游戏设定.md)。武器主动技能、六职业分组、序章与大地图已接入。

战斗组件独立接收场景数据：战场、角色、血条、读条、技能栏、目标选择、特效、飘字、结算均由单个Canvas绘制。赤壁是一组演示数据，系统不写死武将、人数、战场和标题。

## 运行

双击 `启动战斗.command`，或在目录中运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765/`。

`dist/index.html` 已内嵌全部代码和图片，可单独保存、离线打开，也可作为 GitHub Pages 的入口。修改源码后运行 `node scripts/build.cjs` 重建，无需安装依赖。

## 战斗操作

进入即按显式技能规则自动战斗，战斗中没有暂停。没有通用普攻和防御指令；没有可用技能时满条待命。数字均不加千位分隔逗号。

- 点己方姓名切换自动/手动，点头像或长按配置技能：自动姓名和边框为蓝色并有轻微待机动效；手动为白色、头像静止待机，四角显示白色标记。
- 满条的手动角色在己方区域水平居中显示技能，一次只显示一人，按准备完成顺序轮换。技能是正方形图标，下方为名称和有颜色的功能标签。
- 单体攻击/治疗/状态技能先选图标，再点高亮目标的头像。群体和自身技能点击即释放。取消目标选择可再次点同一技能或按 Escape。
- 再点己方姓名可恢复自动；其他人持续战斗。长按头像约1秒打开居中的施法设置，通过横向滑条修改群攻人数、治疗阈值、技能开关和四种输出目标；百分比每档1%，滑到最左端仍保留正常交互颜色；关闭即应用，设置期间不暂停。
- 技能名称在施法者头顶飘起，伤害/回复数字在目标头顶飘起；支持火、雷、木、水、土攻击特效、绿色回复、增益/减益、头像受击红闪、前冲/后仰、命中闪光和暴击震屏。血条主条平滑变化，白条延迟追赶；治疗平滑增长。
- 战后可查看战报、计算因子和重开。战斗中没有指挥弹窗、菜单、确认按钮或倍率栏。

## 接入及验证场景

参见 [战斗系统接入.md](./战斗系统接入.md)。

- 默认：进入《异界三国》主菜单。
- `?scenario=chibi`：赤壁五对五，常规自动战斗。
- `?scenario=encounter`：不同标题、阵容、等级和场地的独立遭遇战，验证复用。
- `?scenario=effects`：特效和操作验证，五名己方初始手动，涵盖五种攻击效果、单/群治疗、自身/友军/敌军状态；使用耐久目标和测试数值，不是正式技能表或数值平衡。
- `?scenario=formation`：以已生成的周瑜验证敌方完整全身图。

敌方恢复为顶部五人横排，按阵容顺序从左到右显示，手机窄屏也保持一排。多敌姓名、血条、读条贴近人物下方；单敌为顶部窄血条，角色位置固定。尚未生成的敌方立绘暂用旧头像，后续按需补齐。

手机375×667和320×568尺寸已实际检查，包括居中设置窗口；超员布局有几何检查。尚未做真机触控测试。

## 结构

- `js/presentation.js`：无逗号数字、血条连续动画和延迟白条。
- `js/character-assets.js`：角色ID与形象版本的独立素材解析。
- `assets/characters/manifest.json`：角色素材真源，改完运行`node scripts/sync-assets.cjs`。
- `js/engine.js`：不依赖DOM的战斗引擎；传入双方阵容、规则、技能和场景元数据。
- `js/rules.js`：旧演示技能ID兼容及通用默认规则。
- `js/weapon-catalog.js`：六职业29武器，月阶87条和日阶87条独立技能数据。
- `js/canvas-battle.js`：Canvas绘制、姓名切换、居中单人技能栏、点选和战后复盘。
- `js/canvas-effects.js`：五种攻击元素、治疗、Buff/Debuff、红闪与震屏。
- `js/data.js`：演示武将与场景工厂；可由正式游戏的剧情系统替换。
- `js/game-rules.js`：难度、武器熟练度、技能方案与被动抽取、姓名验证、本地存档与设置。
- `js/canvas-menu.js`：主菜单、两步人物创建、存档与设置界面。
- `assets/game/manifest.json`：主菜单背景与八种主角全身图、头像区域。
- `js/app.js`：游戏入口，按URL进入主菜单或独立战斗验证场景。
- `assets/README.md`：内置imagegen生成素材及提示词记录。

运行 `node --test tests/*.test.cjs`。测试覆盖战斗规则、四人常规队伍、超员兼容、难度区间与存档迁移、被动人数与品质、四字姓名、存档隔离、等级成长突破100、损坏存档及设置。

战斗已完整切换为地下城堡2数值规则：力量改名武力、魔力改名智力、旧统御迁为体质，生命＝体质×10。伤害按技能属性系数加武器威力，护甲/抗性减伤系数50；月阶29方向共87技能，日阶独立预留。详见[战斗系统规则.md](./战斗系统规则.md)。

将源码目录或单文件版放到 GitHub Pages 即可；本轮未推送或部署。


## 素材进度

角色素材已拆成独立角色ID和版本配置，己方使用头像，敌方优先使用完整立绘。现有武将头像暂存于`assets/legacy/generals-v1.webp`，各角色素材表分别记录裁剪信息。主角形象存于`assets/protagonists/`，由主菜单素材表独立管理。

周瑜的独立全身图已生成并保存为`assets/characters/zhouyu/classic/fullbody.webp`（发布图1024×1536，WebP保留透明）；配套独立头像请求返回HTTP429，战斗头像暂用旧图。其余人物按需逐个生成。各角色目录保留提示词和生成状态，管理方式见[角色素材管理.md](./角色素材管理.md)。


输出技能不再使用自身或目标血量作为施放条件：单体输出设从不/偶尔/始终，群攻人数从至少2人起。治疗仍分别设置自身和队友生命阈值，嘲讽可设置始终。

自动施法规则核对与本作适配见[自动施法规则.md](./自动施法规则.md)。新版自测覆盖群攻优先、两个单体技能轮换、自身/队友分别治疗、四种目标、嘲讽缺失补充、设置草稿和待机状态。


## 同步施法性能

已加入背景缓存、头像/受击纹理预热、文字缓存和特效动画帧缓存。同一目标相同属性的重复光效合并；战斗计算与完整战报不合并、不省略。输入只修改状态，每帧只统一绘制一次；待命AI只在战场或设置变化后重新判断。

`?scenario=stress&profile=1`用于十人同时群攻的压力验证。统计写在Canvas的`data-frame-stats`，不增加游戏界面内容。测量记录见[性能测试.md](./性能测试.md)。

移除原有输出血量限制后，旧的赤壁参数会出现联军失利，这是按新逻辑模拟的结果；当前演示数值仍未作正式平衡。


本轮主角八套原画及张角、张宝、张梁、官兵已替换为统一的年轻写实CG形象，使用剑、扇、匕首、金针、刀、枪、戟、杖、符箓等不同默认兵器。完整路径和生成记录见[人物原画索引](./assets/人物原画索引.md)。

战前准备沿用战斗布局，己方固定四分之一槽宽并居中。单敌人使用窄顶部血条和较大模型，依次展示血条、读条、计时与模型。战斗提示在正中心。对白为左右半身立绘，与下方对话区渐隐融合。

“雷公助我”的教程版包含濒死回满，普通版只有25%闪避及闪避电击；两个版本同名但ID独立，后续敌人默认用普通版。教程采用真实5级成长数据与150～260生命，不影响已创建人物的属性。

可用 `?scenario=tutorial` 单独验证手动教学战，`?scenario=preparation` 单独验证战前准备。它们不写剧情存档。

图片保留原始分辨率并采用质量90的WebP，进入游戏前显示实际资源加载进度，下载、解码完成后进入主菜单；支持缓存与失败重试。

序章已扩展为董卓朝廷与魏蜀吴并立的错世主线，三仙梦境后选择兵器进入大地图。支持《三国志13》60城、共137个地标，有地貌、相邻行路动画、城镇头像交谈、途中事件、独立任务面板、通用战斗与战前回档；英雄招募关卡后续制作。见[主线与大地图.md](./主线与大地图.md)。

当前五维由角色1级基础属性、100基准潜力和等级统一生成。100潜力每级累计4点，60潜力累计2.4点，无随机成长；潜力不直接参与伤害。捏人同排显示当前属性与潜力，存档版本4兼容旧255数值迁移。详见[人物成长规则.md](./人物成长规则.md)。

## 界面与交互打磨（2026-11-09）

主菜单改为游戏真实城池和道路构成的动态舆图，标出许昌、成都、建业及开局行路光点，配合书法标题与朱砂入口。提供按钮悬停、按下反馈；有存档时可直接继续最近旅程，仍保留新游戏、载入、模拟、设置和关于入口。尊重系统减少动态设置，后台页面停止主菜单循环，退出时清理动画与事件。

载入页采用人物肖像存卷卡；菜单、创建、任务、背包、人物与设置面板统一暗纸、旧铜和朱砂的低反光配色及细边框。剧情对白和战斗规则不变。
