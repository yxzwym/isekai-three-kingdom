# 异界三国 · 当前战斗规则

## 当前覆盖规则

- 主角自由职业，其他队友固定武器职业；旧档跨职业兵器退回背包。完整名单见《队友职业一览.md》。
- 扇为火系、杖为雷系，雷系减速不灼烧；技能说明使用“妖物”。
- 潜力档平均值为100、80、60、40；地狱沿用40平均值并加强敌军。
- 体质潜力按战斗定位设定，不采用统率。
- 常山前三条附近支线提供三级挑战；任务未完成项按推荐等级升序。
- 常山剧情敌军仅使用物理攻击，后续逐步加入术士、巫医、弓手与野兽。
- 普通掉落装备含随机属性，独特装备保持固定效果；废弃军堡、芦泽古祠、荒废庄园可重复刷取定向装备。
- 华容道支持拖拽；战斗结果飘字统一字号，暴击加粗。

## 属性和生命

| 本作 | 对应原作 | 用途 |
| --- | --- | --- |
| 武力 | 力量 | 物理技能系数、力速比 |
| 智力 | 魔力 | 计策与治疗技能系数 |
| 体质 | 体质 | 每点体质提供10点生命 |
| 速度 | 速度 | 行动间隔、对方命中计算 |
| 技巧 | 技巧 | 命中、暴击及各技能状态系数 |

五项潜力以100为标准，当前战斗五维由独立1级基础属性、潜力和等级统一计算，可超过100。固定成长见[人物成长规则.md](人物成长规则.md)。基础属性小于等于0按1处理；生命可以为0，闪避和未命中伤害为0。等级通过固定成长改变五维，伤害和生命公式不再额外乘等级系数。武器威力与人物武力分离，装备不能被当成武力直接代入。

常规上阵最多4人，剧情增援可超出4人。通用引擎接受双方任意实际阵容，限制由常规编队层处理。无基础普攻和防御指令，所有行动均由技能配置产生。

## 伤害、治疗和命中

- 技能面板＝技能各项属性系数之和＋武器威力。例如剑的群体破甲为武力×0.8＋武器威力，刀的精准单体为武力×3.75＋技巧×1＋武器威力。
- 物理伤害＝技能面板×暴击倍率×匹配的种族倍率×50÷（50＋目标护甲）。计策伤害将护甲换为抗性；属性加成、穿透或角色被动有明确配置时再计入。结算向下取整，成功命中最低1点。
- 治疗按技能自己的属性系数与武器威力计算，不受护甲和抗性影响，不暴击，可以救起重伤，不能救起阵亡。单体/群体均逐目标结算，不按人数分摊，不按人数额外削弱。
- 命中率＝技能基础命中率＋额外命中＋施法者技巧÷目标速度×30%－闪避率，限制在0～100%。
- 暴击率＝技能基础暴击率＋额外暴击＋技巧÷2000，限制在0～100%；每20技巧增加1个百分点，暴击倍率固定1.5，物理和计策均可暴击。
- 基础伤害不随剩余生命衰减，不使用旧兵力、等级、阵营或乱数乘区；专属被动有明确配置时可按生命变化提供增伤。
- 人型、野兽、龙、灵体和黑暗生物的额外伤害按目标标签判定；普通官兵默认人型。
- 飘字显示本次完整结算伤害，溢出伤害不截为目标剩余生命。吸血按完整结算伤害计算，再受自身最大生命容量限制；反伤按实际承受伤害计算，以真实伤害返还。

## 读条与技能条件

力速比＝min（3，max（1，武力－卸负）÷（速度＋1）），向下取一位小数。卸负当前默认0，给后期装备预留。行动间隔最低0.5秒。首次行动间隔＝1.5秒＋力速比；下一次间隔再加刚用技能的冷却修正。冷却可为负数，如短刃快速技减少1.2秒。不同角色使用自己的属性读条，不为队长写开场技能特例。

战斗不暂停。自动技能来自武器与施法规则：单体从不/偶尔/始终，群攻从不或至少2人起，治疗分别设自己和队友的生命百分比阈值。多个“始终释放”取技能列表最靠上的；状态技能独立维护，已有对应状态时不会重复施放，失效后补上。

点击姓名切换自动/手动；战前点击头像或长按区域配置，一次只设置一人，关闭即应用。手动技能栏一次显示一名满条角色，保留该角色上次选用技能；单体选目标，群体/自身直接释放，其他人持续行动。教学场可通过通用场景控制锁定手动与设置。

## 状态

状态概率、属性系数、持续时间与冷却均逐技能保存。负面状态的施加率按目标抗性每10点降低1个百分点。各分支同名技能的不同参数不合并。

- 嘲讽限制敌方单体伤害技能的目标池；多个嘲讽目标均可选择，敌方默认随机。无视嘲讽技能例外，群攻不受限制。
- 流血、瘟疫、灼烧独立计时，每秒跳伤；回春每秒回复。不把瘟疫合并为普通中毒，不用同一系数覆盖夜莺和夜魇。
- 破甲、破抗、武力/智力/技巧/速度增减直接影响后续结算。加速为对应技能的加值，不再额外叠一个通用百分比。
- 眩晕暂停行动读条，结束后从原进度继续。战斗中的武力、智力、技巧、速度可被削减到0，人物原始属性仍至少1。麻痹按已确认的本作规则降低50%速度，仍可行动。
- 所有人物显示状态图标，消失前5秒闪烁；点击说明显示动态剩余时间。
- 张角“雷公助我”是独立专属被动：25%闪避，闪避后电击；教程版本额外濒死回满，同名但ID不同，普通版本没有此保护。

月阶LV.6为当前默认，日阶LV.7另存数据，强化入口留后期。当前18个普通方向各有3技，不强行给拳击、官兵或专武补到3技。武器熟练度维持独立100成长基准，新主角所有类型开局固定0，不随机，创建时隐藏；练习增长及熟练度修正后续再接入，当前不会暗加伤害乘区。

数据真源为`js/weapon-catalog.js`，原名与参数追溯见`武器技能数值核对.json`。战斗与技能详情共用引擎计算函数，详情显示减伤前面板值，并在数值后用括号标出原公式，例如“57（武力×3.75＋技巧×1＋武器威力）点物理伤害”；状态数值也展示对应算法，不把小数系数四舍五入成另一组参数。敌人属性详情不显示潜力、装备或熟练度，技能图标仍可查看详情。

## 兼容与教程

旧统御先迁为体质，旧255属性按100/255转换为潜力，实际属性从基础值和等级重算。旧地图剩余生命按容量比例迁移，新地图快照版本为3；人物存档版本为4。引擎内部暂保留`soldiers`、`maxSoldiers`和`maxSoldiers(level, constitution)`兼容接口，其含义已是当前/最大生命，等级参数不影响容量。

主角首次必败战以场景显式1点生命覆盖正常容量。教程三兄弟为5级，张角体质21、智力27；官兵与队长为8级，标准官兵体质22、队长33；由统一成长曲线生成。教程节奏通过等级与合理装备调整，不设置固定伤害。张角出营时只赠兵器，不再拨亲兵。

## 四槽装备与武器重整

装备位置为武器、盔甲、饰品、饰品。武器仍保存于unit.weapon，装备保存于equipment.armor、accessory1、accessory2；空槽为null。副手不再是装备位，也不额外提供技能。观察属性页只列基础五维、潜力及生命、护甲、抗性；武器威力在装备页显示。

官兵继续使用通用枪术的单体、群体基础招式；队长额外维护横枪立阵，不再借副手取得嘲讽。张梁及赵云使用新的完整枪方向。状态维护仍由通用优先级决定，不插入角色专用的开局行动。

## 赵云专属被动

- 一身是胆：红色，exclusive，独立于武器。每损失1%生命，伤害增加0.5%，线性增加，上限50%。影响技能伤害、持续伤害及反伤，不增加治疗。伤害与技能详情的当前算法使用同一倍率。
- 七进七出：红色，exclusive。生命下降从阈值上方到达或低于25%、50%、75%，或回复从阈值以下/恰好阈值到超过阈值时，立即把当前进度、累计等待时间与就绪状态同步为读满。过线可重复触发；同一次变化越过多条阈值只填满一次，不囤额外行动。初始化时不会因当前生命低而免费触发；致死不触发、不复活；眩晕中读满仍须解除眩晕才能行动。

统一的生命变化钩子覆盖直接伤害、治疗、吸血、持续伤害、持续治疗、反伤和闪避反击。自身技能附带回复的过线结算放在本次技能进度重置之后，防止读满立刻被抹除。触发时在角色头顶显示被动名及增益特效，不计作一次主动技能、不消耗资源。

被动不进入创建人物随机池，也不随换武器删除；旧赵云存档补齐两个被动并保留既有成长与其他被动。数据位于js/passives.js，生命过线和缺血增伤由通用引擎读取配置，不在赵云剧情里写特殊战斗规则。

## 重伤与救起

采用[重伤法](https://wiki.biligame.com/dxcb2/重伤法)及[游戏机制介绍](https://wiki.biligame.com/dxcb2/游戏机制介绍)的细化说明：

- 友军默认生命归零进入重伤，不能行动。任一有效直接治疗即可救起，不要求治疗量超过最大生命的1%；1%是自动治疗最低阈值，并非复苏门槛。救起从零读条，清除上一次技能额外冷却，首次出手时间重新按力速比＋1.5秒计算。
- 重伤保留已有增减益与嘲讽。致命攻击不会新增控制或属性衰减，但可附加持续伤害；后者按机制页的明确细则处理。持续恢复在重伤时失效，须主动治疗救起。
- 已重伤者再次受到攻击或持续伤害，有独立50%绝对闪避，否则阵亡；不受自身闪避、对方命中或必中特性影响，此绝对闪避不触发普通闪避反应。持续伤害首次造成生命归零，也立即进行此判定。
- 阵亡者不可被通常治疗选中，已有状态清除。致命攻击使目标重伤或阵亡时，该目标不再反伤。己方全部失去可行动者时判负。敌人默认正常死亡；可通过单位woundsEnabled启用，场景rules.wounds=false禁用，夺魂技能ignoreWounds=true直接致死。
- 战后保存重伤/阵亡区别，训练或张宝休整恢复；路遇失败仍回读战前存档。血条显示“重伤”或“阵亡”，手动治疗的目标特效与自动治疗均纳入重伤者。

## 普通武器与专武

普通方向提供默认技能集合。特殊武器可保存完整weapon.skills数组：字符串复用技能模板；对象可用base引用模板，并覆盖名称、scaling、范围、冷却、状态、概率等；不写base则定义全新技能。名称、数量与倍率不依赖职业硬编码，不强制补齐三招。角色被动与武器独立。

内置方天画戟示例仅两招：剑豪的单体杀机暴起（武力×4.8＋武器威力）、剑宗的群体破甲（武力×0.8＋武器威力，65%附加破甲）。火神杖使用同一专武解析途径，只有电击、落雷阵两招。自定义配置生成稳定的局部技能ID，同场不同倍率互不覆盖，存档后ID保持一致；普通方向迁移不覆盖专武。

## 装备、货币及结算界面

18个普通方向各有基础白色武器，另有布衣、皮甲、护心甲三种盔甲及少量饰品。装备品质为白、绿、蓝、橙、红；当前区域随机掉落仅白、绿。武器威力与五维属性分离，物品加成在角色状态和战斗中使用同一结算函数。换装会改变技能或属性，但不因增加生命上限免费回血；人物潜力、被动和成长档案不被改写。

装备采用独立UID，背包与四个装备位置互相交换，不复制或吞掉旧装备；卸武器后使用拳击，读档不会强制重选初始武器。普通商贩出售基础装备，背包提供查看、装备和卸下，不提供出售入口；选中框与物品图标之间留出内边距。金钱余额仅在背包显示，地图左上角不显示。初始盘缠200文；实战敌人掉铜钱，训练只给经验，不刷出钱物。价格、42%逐敌装备掉率与绿装在掉落中的22%占比为本作当前自定配置，非原作数据。

施法选择：缺失的状态维护、有效的始终技能仍按原规则优先；没有始终技能时，满足阈值的治疗优先于偶尔攻击。自由场景设置复用战斗内同一配置面板，并允许将群攻人数设至至少5人；不会因为预览中没有敌人而只允许至少2人。

人物状态采用左侧四个装备格、中间放大的全身模型、右侧预留的结构。立绘按屏幕空间放大，技能图标、被动和属性表放在立绘下方，生命与经验条位于属性之后。属性行距放宽，武器熟练度仅放在详情页。页脚是技能设置、详细属性、队伍设置三个文字按钮，不再用立绘旁的齿轮作为技能设置入口。窗口按实际内容居中，短屏或特殊武器技能较多时可滚动。点击装备格进入筛选后的背包，可装备、卸下；技能图标可查具体公式。武将观察使用只读状态页，仍可查看潜力、装备与技能。

详情页分别显示护甲对应的物理减伤、抗性对应的计策减伤，百分比复用战斗引擎的减伤函数计算，显示至小数点后两位并省略末尾的零。NPC只有确实可接取、推进的任务时显示感叹号，普通闲聊用对话气泡；商贩、疗伤、操练等服务标识保留。

角色弹窗进一步扩大，立绘按可用屏幕空间显示，技能图标放大并加宽间隔。人物立绘使用轻微呼吸动效，脚下锚点保持稳定；动画帧复用技能预览数据，不反复构造战斗实例。经验条仅显示当前经验和升级所需经验的数字。详情的护甲、抗性与五维、熟练度一样使用表格；潜力显示为`100(4)`，括号内为成长函数给出的每级成长，取整仍遵循累计成长规则。

背包、快捷换装、商贩共用固定高度的装备列表，数量和选中状态不改变窗口高度；小屏按屏幕高度收束。装备多时上下滚动，只绘制可见行。右上方提供筛选和排序：品质可多选，装备部位与武器类型可筛选；快捷换装始终限制为当前槽位可用的装备。支持品质、默认顺序、武器威力、五维、护甲、抗性的升降序排序。筛选、排序只改变视图，不改动装备UID或原始背包顺序。

快捷换装页不显示余额，已装备与选中装备均展示武器威力和装备属性。18种普通初始武器实际威力为10，与战斗计算使用同一数值。主角和队友卸下武器后只有拳击，徒手武器威力为0；同伴原武器卸入背包时保留原有威力，避免换人装备后变成另一数值。

普通敌军1人沿用顶部首领血条；2至5人按实际人数分配横排空间，两人左右站立并使用更大的模型，3、4人依次缩小，5人才使用五列。多敌姓名、生命与读条仍贴在人物脚下。超过5人继续换行；场景明确设置的前后排阵型保留，单排中的宽度也按该排人数分配。


## 角色被动补充（2026-11-06）

赵云在一身是胆、七进七出之外新增金色常胜骁勇（物理伤害+10%）、忠胆护身（受到的物理伤害-8%）；张梁新增绿色勇健有力（物理伤害+5%）、白色皮实耐打（受到的物理伤害-2%）。均使用通用被动属性参数，物理减伤不作用于计策或真实伤害；已有同伴、离队驻留记录会补齐且不重复添加。被动按品质从高到低展示，卡片固定四分之一宽度、整行居中。


## 战斗退出与场地

重伤、濒死只作用于我方。敌方生命归零后立即失去目标资格，立绘与血条在500毫秒内淡出并下沉；不留下倒地标签，也不进入可治疗的重伤阶段。最后一名敌人倒下时，普通结算面板等待消失动画完成，战斗结果仍立即提交。

通用战斗默认在计时300秒时开放撤退按钮，不强制结束；允许即时撤退的场景可单独配置。`control.retreatDisabled` 可禁止撤退，序章各教学战设置该标记，包括张角手动教学。撤退沿用战前存档回读，不发战斗奖励。

`js/battle-scenes.js` 提供山贼营寨、林间小径、河岸渡口、乡野官道、村边农田、城内街市六类场景。调用 `BattleScenes.get(id)` 取得独立配置，再传给通用战斗的 `scene`。路遇敌人及任务战读取配置选择场地，素材采用俯视地面构图，没有天空背景或烘焙人物。

## 随机被动的通用结算（2026-11-08）

创建人物的随机被动与武将被动统一注册到 `BattlePassives`，生命、护甲、抗性、伤害、治疗、暴击、穿透、闪避、读条及条件增减伤均由战斗引擎读取。行动回复、吸血、反击、开场护盾与溢出治疗护盾也使用通用结算；持续治疗按施放时的增疗效果确定每跳数值。融合品质仍只预留，不进入开局随机池。

## 敌军临时特质

敌方战斗专用能力也以被动按钮展示，统一白色并另标“临时”。角色观察、战前点击及交战中长按均使用实际战斗配置；招募后移除敌方临时特质。武将招牌被动使用专属紫色，通用资质仍按原品质着色，颜色不改变强度与排序。

| 特质 | 实际效果 |
| --- | --- |
| 免疫眩晕 | 拒绝眩晕；仍可受到麻痹、持续伤害和属性衰减。 |
| 百邪不侵 | 免疫全部负面状态；治疗与有利增益照常生效。 |
| 压制回复 | 来源存活时，对方全体的主动治疗、持续恢复、吸血及行动恢复降低75%。相同来源不叠乘；击败来源后立即恢复。 |
| 无视嘲讽 | 单体攻击的目标池不受嘲讽限制，按自身目标规则选择；群体技能维持原范围。 |
| 限时决战 | 可配置开战1、2、3、5、10分钟后全体击败对方，包括重伤者，不被护盾或濒死恢复阻止；提前击败来源可阻止释放。 |

太史慈建业单挑使用免疫眩晕、压制回复及2分钟限时；他的普通NPC、同行状态不携带这些效果。盗匪头目获得临时免晕，普通杂兵仍可控制。可选强敌分别使用负面免疫、限时与无视嘲讽，须观察后配置队伍。计时按实际战斗时间，手动时停时不会额外推进。

机制形式参考Wiki的[图30强敌条目](https://wiki.biligame.com/dxcb2/图30)与[图33强敌条目](https://wiki.biligame.com/dxcb2/图33)中的免疫及限时毁灭攻击；本作的75%回复压制、各场期限及敌方成长数值是独立的平衡配置。

角色面板与战斗使用同一份被动加成。旧档首次补上生命被动时保留原生命比例，重复读档不再次放大。教程明确指定的1生命不受生命被动影响。护盾以状态图标展示，点击查看当前可吸收伤害；反击不再次触发反击。
