# 第一章：洛阳风起

## 章内目标与结束条件

继续沿用魏、蜀、吴各正式招募至少三人的目标。人数只有下限，不设失效窗口；群雄、黄巾角色单独登记，不占三国名额。达到目标后，洛阳出现讨董接洽与战线任务。各国军师按正式引荐记录，每人发放一次五百文赏钱，离队和重新邀请不会重复领奖。

入梦时三仙请司马懿、诸葛亮、周瑜到场，将主角介绍给三人。三人应允相助寻访人才、联手讨董，并分别邀主角前往许昌、成都、建业；拜访三府的任务详情保留三个独立前往按钮。三国军师现实初见时承接梦中约定：司马懿先核实来历，诸葛亮关心眼下能帮助哪些人，周瑜约定外出寻人与城内接应的分工。军师入队后，由主簿保留复命和办事入口。

洛阳依次经历关前先锋、陷阵守军、温侯拦关、洛阳街垒、府前毒阵、太师府决战。敌人为十五级，以角色成长、装备、专武与可观察的状态组成。若已说服吕布离开，则跳过温侯拦关。战后奖励、准备、撤退、失败回档沿用通用战斗接口。

打败董卓后，主角亲眼见到异影离体，董卓说明自己此前失去身体控制。主角要求先停兵、开仓、放人，再追查来历；此处不揭露异影身份。对话结束显示第一章结束，董卓在洛阳提供招募，地图、委托及尚未完成的招募线继续保留。

各招募线在事情办妥后，由人物说明自己的牵挂和愿望，再由主角按其性格与处境提出落脚、引荐或同行的建议。34条正式招募线统一在 `js/recruitment-intentions.js` 维护去向对话；保留原有任务、奖励和归处。常山结束时，由主角向赵云推荐成都的刘备；常山任务预览隐藏同行之缘，其他任务仍保留。

## 洛阳强敌的搭配要求

- 华雄：厚甲、单体重斩和流血。正面纯物理队难以快速突破，计策输出和治疗更有用。
- 高顺：枪盾守军与后排弩手，嘲讽和反击由通常技能优先级驱动。
- 吕布：天下无双的必暴击与无视护甲保留，厚甲不能解决所有伤害，需要生命、治疗和输出配合。
- 李傕、郭汜：两名前排与淬毒刺客，兼顾单体压力与持续伤害。
- 李儒：护卫在前，毒雾在后；可用驱散、解毒、药草香囊或集中处理后排。
- 董卓：噬魂回息持续回复，重斩和横扫带吸血；诡影附身明确提高最大生命并免疫眩晕，破甲、麻痹、持续伤害仍有效。入队后没有附身效果。

普通讨董前哨已用二十级混合队逐场模拟；吕布守关因真实伤害群攻，需要更强的回复与配合，二十五级回复队可胜，普通同级混合队仍会失利。低等级及纯物理队也有明显失败关卡。该验证使用实际引擎、真实等级、装备与技能，不强设战斗结果。数值仍可随实际游玩反馈继续调整。

## 城内布局与任务入口

英雄稳定排在普通居民前，同组保持原顺序。六人以内三列，更多时四列或五列；最多三排。超过十五人，每页十四位加最后一格“更多”。NPC 和任务面板使用同一套任务标记：青色可接、白色进行中、金色可交付；描边、感叹号和光效提高辨识度。

已入队的人不会同时以常驻 NPC 头像出现。如该人恰是当前任务交谈对象，进入地点时仍可触发交谈，也可通过任务面板“前往”继续。

## 招募条件与君主问询（本轮修订）

新英雄首次加入或在剧情战中临时助阵时，按主角当时等级计算真实属性；赵云仍为三级出场。武将潜力、装备、熟练与天赋不因同步丢失。入队后各自领取经验独立成长，离队再邀及载入不会反复追平主角等级。营地三兄弟作为对手仍固定十级。

张飞交信不再触发战斗，必须先读信、修桥、明确约定切磋。太史慈在北海不进入常驻队伍，也不提前计入吴国人数；完成北海事件后去建业赴约。张飞、太史慈、张辽、黄忠及孙尚香的切磋只允许主角一人参战；失败保留挑战入口，不算赢，也不因失败招到人。单挑对手使用明确的练武兵器，仍按现有成长、装备与技能公式计算，未设固定伤害。

黄忠与华佗的任务凭据来自本地支线，不直接送道具：浏阳“渡边灯火”交付后获得牛筋弓弦，宜城“宜城送药”交付后获得巡诊簿。道具可在背包查看用途，不占装备格，不可装备或出售。此前已交付“渡边灯火”的存档自动补凭据，不重复给钱物。

许昌、成都、建业的丞相及代办人员都提供询问本国君主下落的选项。人数不足时说明失联情形及城内需要留守人手的原因；为该国招募至少五人后，问询会接入曹操乌林、刘备江夏、孙权柴桑的正式接应任务。任务完成后改为平安返回的对白，不再反复说君主失踪。主线三国各三人的讨董门槛仍独立保留；君主救援也不设人数上限。

## 任务推荐与敌方表现补充

普通任务推荐等级从黄巾营地附近的三级起步，按可行陆路距离逐渐增加，以最远的三国都城为十级距离，普通推荐封顶十级。常山、巨鹿及附近村县以三级为主，北海一带约五级。任务推荐与存档等级分开计算，路线距离只缓存一次，不在地图每帧重新寻路。已有明确强度的单挑、君主接应、可选强敌与十五级吕布考验保留独立推荐。

通常招募任务的普通盗匪沿用主角等级并封顶十级；明确配置的 Boss 和固定等级战斗保留原配置。常规五轮清剿默认以二、三人小队为主，最后一轮五人，不再不断堆人数；普通招募中的四人杂兵战改为三人，劫狱外院等明确安排保留四人。小队站位为一、二、四人横排，三人前一后二，五人前一后四；特殊 Boss 可单独配置阵型。

眩晕抵抗以敌方临时白色被动展示，可点击查看。此被动不进入主角随机池，不成为可招募英雄的固有能力；营地正常 NPC 不附带该敌方特质。

所有治疗飘字使用技能计算出的完整治疗量，包括满血和溢出部分；真实恢复及统计仍以生命上限为准。手动可对满血目标施法，自动治疗仍按原有阈值和优先级判断，满血目标不抢占受伤队友的治疗。
