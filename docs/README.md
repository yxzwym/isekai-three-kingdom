# 异梦三国

手机与桌面浏览器可玩的静态网页三国游戏。主菜单、人物创建和战斗由Canvas绘制；姓名输入使用原生输入框支持中文输入法。序章已接入：古道迷雾后的村道冲突、手动雷系教学战、三兄弟对五队官兵，以及黄巾营地对话。

主菜单提供新游戏、载入游戏、设置、关于。创建人物分两步：第一步选择难度、重掷潜力和被动，五项1级属性固定为10，使用五行属性表和三张纵向被动卡片展示，隐藏武器熟练度；第二步输入姓名、选择全身造型。返回上一步保留已有结果。默认初出茅庐及第二个形象；进入即重掷潜力，空名用无名氏，自定义最多四字。只选难度，自由搭配任何武器。地狱与乱世求生的平均潜力为40，初出茅庐为60，天纵之才为80；单项随机1～100，武力与智力倾向互补，总潜力不变。主角剧本保留五项全100。所有难度均可抽到红色被动，越简单概率越高；同品质内按潜力倾向抽取，避免明显偏智却获得物理专用增伤，或偏武却获得计策专用效果。高体质更偏向抗伤与生存，并补充各品质的物理、计策命中被动。重掷只影响潜力和被动技能，旧人物不会重掷。重掷无闪屏，空格仍可操作但不展示说明。

五档难度、开局被动与存档兼容见[新游戏与被动设定.md](新游戏与被动设定.md)。全部武器定位与地下城堡2参考分支见[游戏设定.md](游戏设定.md)。武器主动技能、六职业分组、序章与大地图已接入。

战斗组件独立接收场景数据：战场、角色、血条、读条、技能栏、目标选择、特效、飘字、结算均由单个Canvas绘制。赤壁是一组演示数据，系统不写死武将、人数、战场和标题。

## 运行

双击 `docs/启动战斗.command`，或在目录中运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8765/`。

`dist/index.html` 已内嵌全部代码和图片，可单独保存、离线打开，也可作为 GitHub Pages 的入口。修改源码后运行 `node scripts/build.cjs` 重建，无需安装依赖。

## 画面设计基准

后续界面统一按 **1080×1920 竖屏（9:16）** 设计。窗口只等比例缩放、居中留边，不再按窄窗口切换字号或构图。Canvas 内部沿用 540×960 绘图坐标，每单位对应原尺寸的两个设计像素：正文28px、按钮32px、页面标题40px，主菜单游戏名单独设计。在1920×1080横屏显示器上，游戏区域为607.5×1080；窗口缩小时文字随整个画面一起缩小。

行旅手记右上角可打开「回顾」，保留序章和城镇对话的已读原文，记录随存档保存。装备详情显示当前角色换装前后的实际属性。操练结算展示经验和熟练进度，零铜钱不占奖励栏。

按钮、面板、字号和角饰集中在 `js/ui-theme.js`，主菜单、序章、地图、人物、背包、商店、设置、模拟器及战斗弹窗复用。按钮以32/40/48绘图单位分档（设计像素64/80/96），正文、按钮、标题分别为28/32/40设计像素；保留物品品质和战斗状态的语义颜色。

普通战斗与首领配乐改用低音持续声、稀疏拨弦与低鼓，战斗音乐总线为其他场景的46%，出招时进一步压低音乐。物理、雷、火、土、水、木及计策音效采用独立的低频主体、短瞬态和短尾声；同屏密集音效按并发数收敛响度。非战斗曲谱保留。

战斗特效使用双倍精度贴图，缓存上限192张。敌方形象、血条与手动操作区分离；效果位置以实际人物图像为准，不改变出手时序、伤害、剧情台词或奖励规则。

## 战斗操作

进入即按显式技能规则自动战斗，战斗中没有暂停。没有通用普攻和防御指令；没有可用技能时满条待命。数字均不加千位分隔逗号。

- 点己方姓名切换自动/手动，点头像或长按配置技能：自动姓名和边框为蓝色并有轻微待机动效；手动为白色、头像静止待机，四角显示白色标记。
- 满条的手动角色在己方区域水平居中显示技能，一次只显示一人，按准备完成顺序轮换。技能是正方形图标，下方为名称和有颜色的功能标签。
- 单体攻击/治疗/状态技能先选图标，再点高亮目标的头像。群体和自身技能点击即释放。取消目标选择可点「取消」或按 Escape。
- 再点己方姓名可恢复自动；其他人持续战斗。长按头像约1秒打开居中的施法设置，通过横向滑条修改群攻人数、治疗阈值、技能开关和四种输出目标；百分比每档1%，滑到最左端仍保留正常交互颜色；关闭即应用，设置期间不暂停。
- 技能名称在施法者头顶飘起，伤害/回复数字在目标头顶飘起；支持火、雷、木、水、土攻击特效、绿色回复、增益/减益、头像受击红闪、前冲/后仰、命中闪光和暴击震屏。血条主条平滑变化，白条延迟追赶；治疗平滑增长。
- 战后可查看战报、计算因子和重开。战斗中没有指挥弹窗、菜单、确认按钮或倍率栏。

## 结构

- `js/presentation.js`：无逗号数字、血条连续动画和延迟白条。
- `js/character-assets.js`：角色ID与形象版本的独立素材解析。
- `assets/characters/manifest.json`：角色素材真源，改完运行`node scripts/sync-assets.cjs`。
- `js/engine.js`：不依赖DOM的战斗引擎；传入双方阵容、规则、技能和场景元数据。
- `js/rules.js`：旧演示技能ID兼容及通用默认规则。
- `js/weapon-catalog.js`：六职业29武器，月阶87条和日阶87条独立技能数据。
- `js/canvas-battle.js`：Canvas绘制、姓名切换、居中单人技能栏、点选和战后复盘。
- `js/canvas-effects.js`：五种攻击元素、治疗、Buff/Debuff、红闪与震屏。
- `js/data.js`：演示武将与场景工厂；可由正式游戏的剧情系统替换。
- `js/game-rules.js`：难度、武器熟练度、技能方案与被动抽取、姓名验证、本地存档与设置。
- `js/canvas-menu.js`：主菜单、两步人物创建、存档与设置界面。
- `assets/game/manifest.json`：主菜单背景与八种主角全身图、头像区域。
- `js/app.js`：游戏入口，按URL进入主菜单或独立战斗验证场景。
- `docs/assets/README.md`：内置imagegen生成素材及提示词记录。

运行 `node --test tests/*.test.cjs`。测试覆盖战斗规则、四人常规队伍、超员兼容、难度区间与存档迁移、被动人数与品质、四字姓名、存档隔离、等级成长突破100、损坏存档及设置。

战斗已完整切换为地下城堡2数值规则：力量改名武力、魔力改名智力、旧统御迁为体质，生命＝体质×10。伤害按技能属性系数加武器威力，护甲/抗性减伤系数50；月阶29方向共87技能，日阶独立预留。详见[战斗系统规则.md](战斗系统规则.md)。

将源码目录或单文件版放到 GitHub Pages 即可；本轮未推送或部署。

## 同步施法性能

已加入背景缓存、头像/受击纹理预热、文字缓存和特效动画帧缓存。同一目标相同属性的重复光效合并；战斗计算与完整战报不合并、不省略。输入只修改状态，每帧只统一绘制一次；待命AI只在战场或设置变化后重新判断。

`?scenario=stress&profile=1`用于十人同时群攻的压力验证。统计写在Canvas的`data-frame-stats`，不增加游戏界面内容。测量记录见[性能测试.md](性能测试.md)。

移除原有输出血量限制后，旧的赤壁参数会出现联军失利，这是按新逻辑模拟的结果；当前演示数值仍未作正式平衡。

### 任务、物品与队伍交互打磨

- 任务追踪默认只显示当前篇章；长期目标可手动钉住。钉住数量不设上限，外显列表最多显示三行，超出后可逐项翻看；收起保留首项任务标题和等级。展开或收起不移动 NPC。任务页顶栏提供「追踪／筛选／回顾」，追踪列表复用队伍的长按拖拽、手柄拖动和边缘滚动，排序随存档保存。
- 委托、重复探索与赵云的中山邀请先展示任务目标、推荐等级和任务奖励，再选择「接下委托／答应相助」或「稍后再说」。不接受不改变进度；听说的委托不会自动列入进行中。强制剧情与招募对白保持原流程。「同行之缘」人物卡可打开只读观察，关闭返回原任务。
- 普通商店购入、任务奖励与战斗掉落统一生成随机装备。基础属性围绕原模板浮动，武器威力浮动 15%，基础词条浮动 20%；品质决定原有随机词条数量，词条数值沿用原等级范围。预览只显示范围和随机词条，购入后立即展示这次掷出的实际属性，获得后的结果固定保存；独特装备保持固定属性，旧装备不会重掷。
- 物品列表、奖励和详情明确标记「武器 · 流派／防具／饰品／遗物」，背包筛选与排序改为文本按钮。胜利结算不再展示剧情描述或下一步提示。
- NPC 卡片按四列尺寸排列，缺位行居中，数量减少时不放大。底部人物直接从原图绘制，避免二次缩放与旋转导致模糊。顶部地名与按钮统一垂直居中，显示「地名 · 势力简称」；袁绍、袁术保留全名，没有明确归属只显示地名。
- 常规携行容量扩为八人，默认四人出战、四人备战，队伍面板支持整队轮换。生命、装备、战术与备战顺序随存档保留，战斗和行路中不能轮换。
