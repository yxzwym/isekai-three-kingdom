# 界面与地图素材

2026-11-06：按用户要求改为写实三国RPG风格，材质采用铁、铜、木、布、竹简、汉式札甲；不使用西式魔杖、宝石或欧式板甲。

- `rpg-items-v1.webp`：8列4行，18类武器、3类盔甲、3类饰品、8个常用界面入口；索引以 `js/rpg-icons.js` 为准。
- `rpg-effects-v1.webp`：4列4行，状态和NPC职能图标；不再用于主动技能。
- `assets/map/settlements-v1.webp`：4列2行，城池、乡县、村落、营地、关隘、渡口、树群、山体。背景已单独去除并保留透明度。
- `assets/map/terrain-v1.webp`：3列2行，草地、树林、荒漠、雪地、山地、海面；裁切后镜像平铺以消除硬接缝。

素材由图像生成工具生成，导出WebP质量88并保留原透明度；进入游戏前统一预加载，离线构建内嵌一次。最终资源随项目保存，不依赖生成服务或临时路径。

- `skill-actions-a-v1.webp`、`skill-actions-b-v1.webp`：各8列4行，共64张专用技能动作插画，索引在 `js/skill-icons.js`。54个基础武器技能各有独立图标，另有张角电击、雷阵、拳击和通用兜底；专武可沿用模板或用 `iconId`、`icon.src/crop` 覆盖。装备、状态、技能使用不同图集。

- `copper-coins-v1.webp`：独立的汉式方孔铜钱资源图标，128×128 WebP、质量90、保留透明度；用于金钱奖励，与饰品铜环分开。
